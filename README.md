# RateMySomething

# Mis on:
On frontendi ja backendiga veebileht, kus kasutjad saavad postitada pilte ning hinnata ja kommenteerida teiste kasutajate pilte.

# Arendajad
Kerly Ritsu ja Riho Sepp

# Kuidas projekti käima panna
- Ava projekti kaust visual code'ga
- Ava kaustas "backend" terminalis
- Veendu, et kõik paketid on installeeritud (käsklus: npm i)
- Käivta projekt (käsklus: npm run dev)
